# O contrato público da interface nativa do Duke — versão 2 (DS-2).
#
# Esta é a lista conferida: o `cargo xtask invariantes` a compara com o
# registro de comandos (kernel/src/agent/commands.rs), com o `protocolo`
# (as chamadas, os erros, os eventos, os bits do aviso da malha e os tetos
# do envelope) e com os códigos da política (politica/src/codigo.rs).
# Tirar, renomear ou mudar o tipo de qualquer coisa daqui reprova; o que
# entra no registro dentro do contrato — um parâmetro novo de um comando
# daqui, uma chamada, um tipo de evento, um bit, um código — reprova até
# entrar aqui também, revisado. O que está aqui é o que um programa de fora
# do repositório pode usar e continuar usando: ver docs/SDK.md.
#
# As regras do contrato (DS-2):
#   - só cresce dentro da versão: comando novo, parâmetro opcional novo,
#     campo novo num resultado, tipo de evento novo, bit novo, código novo;
#   - um nome nunca muda de sentido;
#   - o que o kernel não conhece ele recusa, nunca ignora;
#   - o programa ignora o que não conhece no que recebe;
#   - remover só numa versão maior, por decisão própria, e o removido é
#     recusado;
#   - uma versão viva por kernel.
#
# A forma das linhas:
#   versao  <n>                         protocolo::usuario::nativo::VERSAO
#   chamada <NOME> <numero>             protocolo::usuario::numero
#   erro    <NOME> <numero>             protocolo::usuario::erro
#   evento  <NOME> <numero>             protocolo::usuario::evento::tipo
#   malha   <NOME> <valor>              protocolo::usuario::evento::malha
#   nativo  <NOME> <valor>              protocolo::usuario::nativo (os tetos)
#   codigo  <NOME> <valor>              politica::Codigo
#   comando <nome>                      um comando do contrato
#   param   <comando> <nome> <tipo> <obrigatorio|opcional>
#           o tipo: inteiro, texto, intencao, booleano, lista
#
# A forma binária do programa — o ELF dos dois alvos, o `usuario.ld`, a
# entrada `principal` e a nota `Duke` com `duke-manifesto 1` — também é
# contrato, sem mudança de formato; ela é conferida na carga de cada
# programa, e não por esta lista.
